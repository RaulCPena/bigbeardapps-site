# Big Beard Apps - Logo Design System
**Approved Version:** Beard Icon on Coffee Cup
**Date:** September 25, 2026

---

## Core Design Elements

### Character
- **Appearance:** Bearded developer based on Raul's likeness
- **Skin Tone:** Light/fair complexion
- **Facial Features:** 
  - Rectangular glasses (prominent)
  - Impressive salt-and-pepper/gray full beard
  - Dark hair on top (short/neat)
  - Friendly, approachable expression
  - Visible eyes behind glasses

### Brand Elements
- **Headphones:** Cyan (#00B5E2) - represents coding/focus mode
- **Coffee Cup:** Orange (#FF9F1C) with beard icon symbol
- **Clothing:** Navy (#0D1B2A) hoodie - developer aesthetic
- **Code Brackets:** </> visible on laptop or integrated into design

### Brand Symbol
- **Primary Symbol:** Beard icon on coffee cup
- **Meaning:** Combines "Big Beard" brand identity with developer culture (coffee + coding)
- **Style:** Simple, clean line art that's recognizable at any size

## Color Palette

### Primary Colors
```
Navy Blue:    #0D1B2A  (Main brand color, text, backgrounds)
Cyan:         #00B5E2  (Accent, highlights, "APPS" text)
Orange:       #FF9F1C  (Coffee cup, warm accent)
```

### Supporting Colors
```
White:        #FFFFFF  (Backgrounds, reverse text)
Light Gray:   #8B8B8B  (Subtitle text, secondary info)
Dark Gray:    #2A2A2A  (Dark mode backgrounds)
```

### Usage Rules
- Navy + Cyan = Primary combination
- Orange = Accent only (coffee cup, highlights)
- Never use orange as primary text color
- Maintain contrast ratios for accessibility (WCAG AA minimum)

---

## Typography

### Display Font (Logo Text)
- **Font Family:** Bold Sans-Serif (similar to: Inter Bold, SF Pro Display Bold, Helvetica Neue Bold)
- **"BIG BEARD":** Navy, Bold, larger size
- **"APPS":** Cyan, Bold, same size as "BIG BEARD"

### Subtitle Font
- **Font Family:** Regular Sans-Serif
- **"DEVELOPMENT • DESIGN • DEPLOY":** Gray, Regular weight, smaller size
- **Bullet Character:** • (centered dot)

### Guidelines
- Never substitute fonts - if unavailable, use system sans-serif
- Never artificially bold or italic the logo text
- Text should always be legible at small sizes

---

## Clear Space & Sizing

### Minimum Clear Space
- Leave space equal to the height of the "B" in "BIG BEARD" around all sides
- No other logos, text, or graphics in this space
- Ensures logo breathes and remains prominent

### Minimum Sizes
- **Digital:** 120px wide minimum (smaller = icon only)
- **Print:** 1 inch wide minimum  
- **Favicon:** 32×32px (icon only, simplified)
- **Social Profile:** 400×400px minimum

### Maximum Sizes
- No maximum, but maintain aspect ratio
- Don't stretch or distort
- Scale proportionally only

---

## File Formats to Generate

### For Web
- **PNG** (transparent background) - Main usage
- **SVG** (vector) - Scalable, no quality loss
- **WebP** (modern browsers) - Smaller file size

### For Print
- **PDF** (vector) - Highest quality
- **EPS** (vector) - Compatible with older software
- **PNG** (300 DPI) - Raster backup

### Favicon Formats
- **favicon.ico** (16×16, 32×32, 48×48 multi-size)
- **PNG** (96×96 for modern browsers)
- **apple-touch-icon.png** (180×180 for iOS)

## Usage Guidelines

### ✅ DO:
- Use approved logo files only
- Maintain original proportions
- Use on contrasting backgrounds
- Ensure logo is clearly visible
- Use icon version when space is limited
- Follow color specifications exactly
- Leave adequate clear space

### ❌ DON'T:
- Stretch, squash, or distort the logo
- Change the colors
- Rotate the logo
- Add effects (drop shadows, glows, outlines)
- Place on busy backgrounds that reduce legibility
- Alter the character's appearance
- Remove or modify the beard icon
- Change the fonts
- Recreate or redraw the logo

## Accessibility

### Contrast Ratios
- Navy on white: 15.96:1 (AAA) ✓
- Cyan on white: 2.58:1 (Fails - use for accents only)
- White on navy: 15.96:1 (AAA) ✓
- Orange on white: 4.17:1 (AA) ✓

### Alt Text
- **Full Logo:** "Big Beard Apps logo - Independent iOS app development"
- **Icon Only:** "Big Beard Apps icon"
- **Wordmark:** "Big Beard Apps"

### Screen Reader Considerations
- Logo images should have appropriate alt text
- Don't rely on logo alone to convey information
- Ensure text version of brand name is always present
