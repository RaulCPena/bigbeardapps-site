## Color Palette for Banners

Use these exact colors for consistency:

**Backgrounds:**
- Dark: `#0d0c0a` (your site's dark ink color)
- Light: `#FDF8F2` (your site's cream color)
- Navy: `#0D1B2A` (brand navy)

**Accents:**
- Cyan: `#00B5E2` (headphones, APPS text)
- Orange: `#FF9F1C` (coffee cup)
- Gold: `#D4922A` (your site's amber accent)

**Text:**
- On Dark: `#FFFFFF` white
- On Light: `#0D1B2A` navy
- Secondary: `#8B8B8B` gray

## Tools You Can Use

### Free Online Tools:
- **Canva:** Import logos, drag-and-drop banner creation
- **Figma:** Professional design tool, free tier available
- **GIMP:** Open-source Photoshop alternative
- **Photopea:** Browser-based Photoshop clone

### Quick Workflow:
1. Open banner template in your tool
2. Import `bigbeard-horizontal.png` or `bigbeard-logo.png`
3. Add background color from palette above
4. Add text (website URL, tagline)
5. Export at platform's recommended size
