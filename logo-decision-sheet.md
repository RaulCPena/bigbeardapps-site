# Big Beard Apps Logo Decision Sheet
**Date:** September 25, 2026

## Overview
New logo design for Big Beard Apps replacing the current character with Apple MacBook (trademark concern). This logo represents the solo iOS developer story without trademark issues.

---

## Logo Concept
**Design:** Bearded developer with headphones, coffee cup, code brackets  
**Story:** Solo indie developer grinding away on iOS apps in spare time  
**Key Elements:**
- Bearded developer (your brand identity)
- Headphones (focus mode, late night coding)
- Coffee cup with code brackets (developer fuel)
- Code brackets </> (iOS/coding focus)

**NO trademark issues:** Generic laptop, no Apple logos visible

---

## Logo Variations

### 1. Light Mode / Web Version
**Background:** White or transparent  
**Colors:**
- Navy blue (primary)
- Bright cyan (secondary)
- Orange (accent)
- White (highlights)

**Use cases:**
- bigbeardapps.com main site
- Light mode web pages
- Email signatures
- Printed materials on white paper
- Business cards

---

### 2. Dark Mode Version
**Background:** Dark (#0d0c0a charcoal or black)  
**Colors:**
- Bright cyan (primary - pops on dark)
- White (secondary)
- Orange (accent)
- Lighter blue tones for contrast

**Use cases:**
- Dark mode website toggle
- Social media posts (X, Mastodon posts with dark backgrounds)
- Developer presentations
- GitHub profile
- Discord/Slack avatars

---

### 3. Circular Badge Version
**Format:** Full circle with border  
**Design:** Character centered in circular frame  

**Use cases:**
- Social media profile pictures (X, Mastodon, Bluesky, GitHub)
- Favicon (simplified version)
- App Store developer profile
- Stickers
- Buttons/pins

---

### 4. Square App Icon Version
**Format:** Rounded square (iOS app icon style)  
**Design:** Fits within standard app icon dimensions  

**Use cases:**
- Apple App Store developer page
- Website apple-touch-icon
- App marketing materials
- Press kit assets

---

## Current Logo Issues (being replaced)
❌ **Problem:** MacBook with visible Apple logo = trademark infringement risk  
❌ **Problem:** Too detailed for small sizes (embroidery, favicons)  
❌ **Problem:** Plaid shirt pattern doesn't scale well  

✅ **New logo solves:** Generic laptop (no logos), cleaner lines, better scalability

## Manufacturing Capabilities

### Hat Applications
- **Woven Patch:** Best method - captures all detail and colors
- **Patch Size:** ~3.5" diameter on Flexfit 6511 front panel
- **Side Text:** bigbeardapps.com embroidered in white

### Stickers
- **Die-cut vinyl stickers:** Full color, durable
- **Sizes:** 2"–4" diameter work well
- **Background:** Light or dark versions available

### Apparel
- **Direct-to-garment printing:** Full color on t-shirts, hoodies
- **Screen printing:** Best for bulk orders (simplified version)
- **Embroidery:** Requires simplified version or woven patch

## Comparison to Other Brand Logos

### HuntMark
- **Style:** Icon-only (topographic + tree)
- **Approach:** Minimal, symbolic
- **Works because:** Visual metaphor is clear (map + location)

### Gunmark  
- **Style:** Icon-only (target/reticle + G)
- **Approach:** Geometric, tactical
- **Works because:** Simple shapes = instant recognition

### Big Beard Apps
- **Style:** Character illustration + text
- **Approach:** Story-driven, personality
- **Works because:** Shows the human behind the apps
- **Consideration:** More complex than the other two, but tells a richer story

## Recommendation

**Primary logo:** Light mode version (front-facing character)  
**Why:** Most versatile, works across most use cases

**Secondary:** Dark mode version for dark backgrounds  
**Why:** Ensures visibility and impact on social media, dark mode sites

**Social media:** Circular badge version  
**Why:** Fits profile picture format perfectly

**Simplified version:** Consider creating an ultra-simple version (just the beard + code brackets?) for very small sizes like favicons
