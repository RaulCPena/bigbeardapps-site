## Implementation Steps

### Step 1: Create New Logo Files
Generate these files:
- `bigbeard-logo.png` (512×512 or similar, light mode)
- `bigbeard-logo-dark.png` (512×512, dark mode)
- `bigbeard-icon.png` (256×256, simplified)
- `favicon-96.png` (96×96, for browser tabs)
- `apple-touch-icon.png` (180×180, for iOS)
- `og-card.png` (1200×630, social sharing)

### Step 2: Replace Files in /assets/
```bash
# Backup old logo first
cp /workspace/assets/bigbeard-logo.png /workspace/assets/bigbeard-logo-OLD.png

# Replace with new files
# (We'll generate these)
```

### Step 3: Update HTML (if needed)
Most pages use the bba:head template which auto-updates, but check:
- Nav bar references
- Footer references

### Step 4: Add Dark Mode Support
Add to site CSS:
```css
@media (prefers-color-scheme: dark) {
  .site-nav__brand img {
    content: url('/assets/bigbeard-logo-dark.png');
  }
}
```
